# 宠物管家

宠物管家是一个记录吃饭、喝水、排便、尿尿的小型 PWA。它支持自定义宠物名字、资料、照片、本地离线记录、趋势预测、数据可视化和 Vercel Blob 云端自动同步，适合在手机浏览器里当作日常照护工具使用。

## 功能

- 快速记录喝水、吃饭、排便、尿尿
- 喝水、吃饭主视图按次数展示，默认记录量分别为 `607ml` 和 `465g`
- 可在资料配置中设置本轮喝水目标次数、本轮吃饭目标次数
- 排便状态记录：正常、少量、拉稀、偏软、偏干
- 首页预测下一次吃喝上厕所时间，并提示距离上次多久
- 过了预测时间后会给出“该喝水啦 / 该排便了”等提醒
- 详细数据页：本轮概览、次数趋势、饮食用量、记录占比、最近记录表
- 宠物名字、物种、品种、年龄、照片可编辑
- 历史记录可编辑、删除，也可批量添加
- 日志支持按日历查看
- 同步码一键绑定和复制
- 基于 IndexedDB 的本地存储
- 基于 Vercel Blob 的云端自动同步
- PWA 支持，可离线访问已缓存页面

## 技术栈

- 原生 HTML / CSS / JavaScript
- Dexie + IndexedDB
- Chart.js
- Vercel Serverless Function
- Vercel Blob

## 本地运行

```bash
npm install
vercel dev
```

如果只想预览静态页面，也可以用：

```bash
python3 -m http.server 4173
```

云端同步接口需要 Vercel Blob 环境变量。项目绑定 Vercel 后运行：

```bash
vercel env pull .env.local
```

## 数据说明

记录会优先保存在当前浏览器的 IndexedDB 中。绑定同一个同步码后，应用启动时会自动从云端合并记录，新增、修改、删除或清空记录后会自动上传。页面处于前台时每 15 秒检查云端更新，切回页面或网络恢复时立即检查；未上传的改动会在网络恢复后重试。后台或锁屏时，手机可能暂停网页，重新打开后会继续同步。同步码用于定位同一份云端数据，请妥善保存。
